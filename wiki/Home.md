# Справка Словоплёт Beta

[← Главная beta](../README.md)

Здесь описан экспериментальный Android-канал с обновлением веб-компонентов.
Справка, сборки и предварительные релизы теперь находятся в отдельном репозитории.
[Перенос и совместимость](../docs/MIGRATION.md) объясняют, почему старый адрес
компонентов сохранён для APK 3.0 / 3.0.1.

| Задача | Куда перейти |
|---|---|
| Поставить beta рядом с обычной игрой | [Установка Android](Android.md) |
| Проверить 3.0 → 3.0.1 без установки APK | [Сценарий тестирования](../docs/TESTING.md) |
| Понять версии оболочки и компонентов | [Версии](Versions.md) |
| Разобраться в загрузке и откате | [Архитектура](Architecture.md) |
| Узнать поведение без сети | [Офлайн](Offline.md) |
| Вспомнить правила игры | [Правила](Rules.md) |
| Найти причину проблемы | [Вопросы](FAQ.md) |
| Подготовить следующий выпуск | [Для разработчика](../docs/RELEASING.md) |
| Сообщить результат теста | [Обратная связь](../CONTRIBUTING.md) |

**Текущая проверка:** оболочка 3.0 получает компоненты 3.0.1. Контрольный APK
3.0.1 нужен для отдельной чистой установки, а не для прохождения этого сценария.
