# Beta без интернета

[Справка beta](Home.md) · [Сценарий проверки](../docs/TESTING.md)

Без сети используются последние подтверждённые компоненты. При первой
установке это встроенная версия из APK; после успешного OTA — установленный снимок.

| Действие | Без сети |
|---|---|
| Запуск интерфейса и случайное слово | Доступны на сохранённых данных |
| Применение уже загруженных компонентов | Не требует повторного скачивания |
| Проверка и получение новой версии | Нужен интернет |
| Онлайн-профиль, рейтинг и слово дня | Нужен игровой сервер |

Офлайн-партии не отправляются в общий рейтинг. Удаление beta-приложения или
очистка его данных удаляет локальный снимок, настройки и автономную статистику.

## Проверка сохранения обновления

1. Доведите APK 3.0 до компонентов 3.0.1 [по инструкции](../docs/TESTING.md).
2. Дождитесь полного запуска игры, затем выйдите кнопкой «Назад» с главной.
3. Отключите сеть и снова откройте beta.
4. Убедитесь, что окно beta по-прежнему показывает компоненты **3.0.1**.
5. Сыграйте случайное слово. Ошибка фоновой проверки обновлений без сети не должна мешать партии.

Сворачивание возвращает в уже открытый экран, а не обязательно создаёт новый
запуск оболочки. Для теста сохранения версии нужен полный выход и запуск.
