# История версий

## Beta: оболочка и компоненты

[Справка beta](Home.md) · [История выпусков](../CHANGELOG.md)

В beta две версии: APK задаёт возможности Android-оболочки, а компоненты —
содержимое игры. Их номера после обновления могут различаться.

| Что установлено | Версия в Android | Версия компонентов в игре | Значение |
|---|---|---|---|
| Исходный APK 3.0 | 3.0 | 3.0 | Начальная точка проверки |
| APK 3.0 после OTA | **3.0** | **3.0.1** | Нужный результат: APK не переустанавливался |
| Контрольный APK 3.0.1 | 3.0.1 | 3.0.1 | Чистая установка; OTA-переход не проверен |

| Поле | 3.0 | 3.0.1 |
|---|---|---|
| `versionCode` APK | `30000` | `30001` |
| Ревизия веб-компонентов | `30000` | `30001` |
| Тег GitHub | `beta-v3.0.0` | `beta-v3.0.1` |

Установленную версию смотрите в окне **«Обновления beta»**. Подписанный
[манифест канала](../ota/manifest.json) сообщает о доступных компонентах, а не
о том, что уже установлено на конкретном телефоне.

GitHub считает beta-выпуски предварительными (`prerelease`). Ссылка
[releases/latest](https://github.com/iluhin/app.slovoplet/releases/latest) ведёт
на стабильный выпуск и не используется для проверки компонентов beta.

Полный формат ревизий и совместимости — в [описании канала](../ota/README.md).
