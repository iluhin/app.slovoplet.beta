# Исправление идентификатора и перенос beta

[Главная beta](../README.md) · [Установка](../wiki/Android.md) · [Проверка обновления](TESTING.md)

## Переход на beta3.1

Исправленные com-сборки 3.0/3.0.1 получают компоненты 3.1 по OTA без установки APK.
Для нативных виджетов и шорткатов установите APK3.1 поверх исправленной beta:
пакет и сертификат совпадают, code30100 больше 30000/30001.
Локальные данные сохраняются обычным обновлением Android.
Сначала [проверьте OTA](TESTING.md), затем установите новый APK.
Первоначальные con-пакеты остаются другим приложением.

## Исправленная сборка r2 — 20 ноября 2026

Правильный идентификатор: **com.iluhin.fiveletters.beta**.
Первоначальные APK по ошибке использовали con.iluhin.fiveletters.beta.
Имя пакета и сертификат подписи — разные параметры. Оба исправленных APK
подписаны прежним сертификатом владельца, но Android считает com и con разными приложениями.

Для перехода установите исправленный APK 3.0 из beta-v3.0.0-r2.
Он может работать рядом со старым con-пакетом и стабильной игрой.
Локальная партия и настройки старого пакета автоматически не переносятся.
Серверный профиль доступен после входа под прежним именем.

## Оболочка и компоненты

| Файл | Версия Android | Компоненты | Назначение |
|---|---|---|---|
| Исправленный APK 3.0 | 3.0, код 30000 | 3.0 | Начало проверки OTA |
| Он же после обновления | 3.0, код 30000 | 3.0.1 | Обновление без установки нового APK |
| Исправленный APK 3.0.1 | 3.0.1, код 30001 | 3.0.1 | Контрольная чистая установка |

Оба исправленных APK используют независимый канал нового репозитория:
https://raw.githubusercontent.com/iluhin/app.slovoplet.beta/main/ota/

Все подписанные payload содержат правильный applicationId и URL этого канала.
Файлы APK, подписанные манифесты и ZIP пересобраны; их контрольные суммы обновлены.
Ключ владельца и формат RSA/SHA-256 сохранены.

## Старый технический канал

Старая ветка app.slovoplet:beta обслуживает только первоначальные con-сборки:
https://raw.githubusercontent.com/iluhin/app.slovoplet/beta/ota/

Исправленные com-сборки не используют её. Старые APK не могут изменить
идентификатор или закреплённый origin через обновление веб-компонентов.
Исторический [протокол первоначального переноса](verification/migration.json)
содержит прежние суммы, а не контрольные суммы исправленных сборок.

Стабильная игра и её релизы остаются в [основном репозитории](https://github.com/iluhin/app.slovoplet).
