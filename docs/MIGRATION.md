## Новое место

Документация, история beta, план развития, справка, APK 3.0 / 3.0.1 и архивы
компонентов находятся в [app.slovoplet.beta](https://github.com/iluhin/app.slovoplet.beta).
Основная ветка здесь — main, отдельная ветка beta для публикации не требуется.

Исходный снимок переноса:
[app.slovoplet:beta, 19664d6](https://github.com/iluhin/app.slovoplet/commit/19664d683d0a8bb3e8d9ded3fb54a21a53a19424).
Стабильная main и её история не переносятся и не переписываются.
Обложка сохранена из последнего оформления владельца: [5f28749](https://github.com/iluhin/app.slovoplet/commit/5f28749).

## Совместимость уже выпущенных APK

| Назначение | Адрес |
|---|---|
| Документация и новые beta-релизы | https://github.com/iluhin/app.slovoplet.beta |
| Копия подписанного снимка 3.0.1 | https://raw.githubusercontent.com/iluhin/app.slovoplet.beta/main/ota/manifest.json |
| Канал, закреплённый в APK 3.0 / 3.0.1 | https://raw.githubusercontent.com/iluhin/app.slovoplet/beta/ota/manifest.json |

В старых APK закреплён весь доверенный origin каталога OTA. Загрузчик не следует
HTTP-перенаправлениям и не принимает компоненты с другого origin. Поэтому старая
ветка сохраняет ota/ с прежними подписанными файлами. Удалять её, менять адреса
в подписанном JSON или заменять манифест перенаправлением нельзя: старые APK
потеряют возможность обновления.

Копия ota/ в новом репозитории совпадает с исходником побайтно. Подписанные URL
внутри payload указывают на старый адрес; наличие копии не переключает уже
установленное приложение на новый сервер файлов.

## Что изменилось при переносе

- Ссылки загрузки и справки ведут в новый beta-репозиторий.
- APK, ZIP, манифесты, компоненты и открытый ключ сохраняются без изменения байтов.
- Версии 3.0 / 3.0.1, подпись приложения и пакет con.iluhin.fiveletters.beta остаются прежними.
- Для теста по-прежнему устанавливается APK 3.0, затем компоненты 3.0.1 приходят внутри игры.
- Стабильные версии находятся в [app.slovoplet](https://github.com/iluhin/app.slovoplet/releases).

## Следующая оболочка

Следующий нативный APK должен закрепить новый origin:
https://raw.githubusercontent.com/iluhin/app.slovoplet.beta/main/ota/

Его нужно подписать прежним сертификатом с увеличенным versionCode, подготовить
подписанный манифест с совместимыми URL и проверить обновление существующей beta.
Это отдельный выпуск оболочки, не выполненный одним переносом документации.
Пока поддерживаются APK со старым origin, их технический канал должен сохраняться.
