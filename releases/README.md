Если APK 3.1 уже вылетает, установите APK 3.1.1 поверх beta, без удаления данных.
Исправление нативного кода требует APK. Старые исправленные 3.0/3.0.1 могут
проверить OTA компонентов 3.1.1 до установки нового APK.

Все beta-выпуски предварительные. Стабильная история находится
в [основном репозитории](https://github.com/iluhin/app.slovoplet/releases).
