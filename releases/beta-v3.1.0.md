# 3.1 beta — виджеты, шорткаты и реальное обновление компонентов

Функции из дорожной карты стабильной 2.8 перенесены в отдельную beta 3.1.

## Что нового

- Четыре Android-виджета: статистика, слово дня, быстрый старт, рейтинг.
- Динамические шорткаты для новой/продолжения игры, слова дня, рейтинга и профиля.
- Безопасный локальный снимок: цвета без букв, раздельная автономная статистика, дата рейтинга.
- Предпросмотр виджетов в игре, работающий также после OTA на старой оболочке.
- На главной и в справке версии оболочки, компонентов и сайта показаны отдельно.

## Как проверить именно обновление

На установленной исправленной beta 3.0 / 3.0.1 откройте окно beta и получите
компоненты 3.1. После партии примените их без установки APK.
Оболочка останется 3.0 / 3.0.1, компоненты станут 3.1.
Нативные виджеты так не добавляются: для них отдельно установите APK 3.1 поверх com-beta.

| Файл | Назначение |
|---|---|
| slovoplet-beta-3.1.apk | Чистая установка или обновление оболочки для виджетов |
| manifest-3.1.json | Подписанный снимок компонентов 3.1, revision30100 |
| components-3.1.zip | Полный архив веб-части для просмотра |
| checksums.json | SHA-256 подготовленных файлов |

Пакет com.iluhin.fiveletters.beta; прежний сертификат владельца.
Android 7.0+, динамические шорткаты — Android 7.1+.
