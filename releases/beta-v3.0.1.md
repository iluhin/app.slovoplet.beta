# 3.0.1 beta — проверка обновления без переустановки APK

**Целевая версия компонентов для установленной beta 3.0.**

| Параметр | Значение |
|---|---|
| Компоненты | **3.0.1**, ревизия `30001` |
| Совместимая оболочка | Сборки `30000–39999` |
| Изменённый файл | `assets/beta-release.json` |
| Содержимое загрузки | **152 байта компонента**, подписанный манифест отдельно |
| Повторно используемые файлы | **9** |

В окне beta после применения должно быть видно:

> Оболочка APK 3.0 · Компоненты 3.0.1
>
> Проверка OTA пройдена.

Это демонстрационное обновление механизма доставки. Правила игры и нативная
оболочка в переходе не меняются.

## Основной сценарий

Установите **APK 3.0 из [начального beta-выпуска](https://github.com/iluhin/app.slovoplet.beta/releases/tag/beta-v3.0.0)**,
получите компоненты 3.0.1 внутри игры и примените их после партии.
**Контрольный APK 3.0.1 из этого выпуска для теста OTA не нужен.**

После полного выхода и запуска без сети подтверждённые компоненты 3.0.1
должны сохраниться. Версия установленного APK в Android останется 3.0.

## Файлы выпуска

- `manifest-3.0.1.json` — подписанный снимок манифеста; текущий указатель опубликован в beta-канале.
- `components-3.0.1.zip` — полный снимок веб-части для просмотра; приложение скачивает отдельные компоненты.
- `slovoplet-beta-3.0.1.apk` — контрольный файл для чистой установки и сверки.
- `checksums.json` — контрольные суммы подготовленных файлов.

Проверка опубликованного HTTPS-канала Java-загрузчиком подтвердила: один файл
на 152 байта, девять повторно используемых файлов, сохранение 3.0.1 после
подтверждения и перезапуска. Это не запись проверки с Android-телефона:
устройство/WebView и 30-секундный контроль запуска ещё требуют тестирования.
