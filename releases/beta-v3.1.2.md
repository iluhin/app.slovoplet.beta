# 3.1.2 beta — обновления APK и виджеты в стиле игры

## Обновления

Теперь новое нативное приложение предлагается отдельным всплывающим окном
с описанием версии и кнопкой «Обновить», как в стабильной игре.
Компоненты продолжают обновляться по OTA; их версия не скрывает новую версию APK.
Уведомление приходит и на старую оболочку после применения компонентов 3.1.2.
При нажатии APK открывается в браузере для обычной установки поверх beta.
Партия не прерывается; «Позже» откладывает только конкретную версию.

## Виджеты

Четыре самостоятельных оформления из элементов игры: шесть выбранных тем,
плитки, контрастные кнопки, график попыток, строки рейтинга и крупный быстрый старт.
Есть компактные и широкие композиции, пустые состояния и сохранённые данные без сети.
Часовой пояс слова дня — Europe/Moscow. Фоновых обращений к игровому серверу нет.

Для нового оформления нужен APK 3.1.2. Установите его поверх beta без удаления
или очистки данных. Пакет com.iluhin.fiveletters.beta, прежний сертификат владельца,
versionCode 30102. Исправление вылета из 3.1.1 сохранено; сборка использует официальный SDK 34.

Вложения: APK, полный ZIP компонентов, подписанный манифест и SHA-256 checksums.
