# 3.0 beta — оболочка и обновление компонентов

**Начальная установка для проверки OTA 3.0 → 3.0.1.**
Основа игры — стабильная 2.7.2. Beta устанавливается рядом с обычным Словоплётом.

| Параметр | Значение |
|---|---|
| Приложение | Словоплёт β |
| Пакет | `con.iluhin.fiveletters.beta` |
| Оболочка APK | **3.0**, сборка `30000` |
| Встроенные компоненты | **3.0**, ревизия `30000` |
| Совместимость | Android 7.0+ |
| Подпись | Прежний сертификат владельца проекта |

## Что нового

- Отдельный beta-канал, версии оболочки и веб-компонентов видны раздельно.
- Загрузка изменённых веб-файлов вместо установки всего APK.
- Подписанный манифест, проверка SHA-256, совместимости, размеров и путей.
- Подготовка в отдельной папке, применение после партии и подтверждение запуска.
- Откат к рабочему снимку при неудачном старте и блокировка неудачной ревизии.

## Как проверить

1. Скачайте и установите **slovoplet-beta-3.0.apk** из этого выпуска.
2. Запустите игру с интернетом и откройте **«β · Готова 3.0.1»** внизу.
3. Завершите партию, затем нажмите **«Применить без установки APK»**.
4. Проверьте результат: **оболочка APK 3.0 · компоненты 3.0.1**.

Системный установщик при обновлении компонентов не появляется, а версия APK в
Android остаётся 3.0. Контрольный APK 3.0.1 для этого сценария **не устанавливайте**.

## Файлы и состояние проверки

- `slovoplet-beta-3.0.apk` — установочный файл для начала теста.
- `components-3.0.zip` — снимок исходной веб-части для просмотра.
- `manifest-3.0.json` — подписанный исходный манифест.
- `checksums.json` — контрольные суммы подготовленных файлов.

Сборка, подпись, Java-загрузчик и браузерный интерфейс проверены автоматически.
Установка и работа на реальном Android/WebView пока ждут проверки устройством.
Нативный код и ресурсы оболочки по-прежнему требуют нового APK; загрузка
компонентов работает при запущенной игре. Это предварительный выпуск, он не заменяет стабильный Latest.
