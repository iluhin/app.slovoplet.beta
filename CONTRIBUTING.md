# Участие в beta-тестировании

[Главная beta](README.md) · [Как проверить обновление](docs/TESTING.md)

Перед отчётом посмотрите версии в окне «Обновления beta». Начните с установки
APK 3.0 и обновления компонентов до 3.0.1 — [пошаговый сценарий](docs/TESTING.md).

## Сообщить о проблеме

[Открыть issue с пометкой beta](https://github.com/iluhin/app.slovoplet.beta/issues/new?title=%5Bbeta%5D%20)
и заполнить:

```text
[beta] Короткое название проблемы

Модель устройства:
Android:
Версия Android System WebView / Chrome (если известна):
Версия оболочки APK:
Версия компонентов:
Как установлен APK: чистая установка / поверх прежней beta:
Состояние сети: Wi-Fi / мобильная / без сети:

Шаги:
1.
2.
3.

Ожидалось:
Получилось:
Точный текст ошибки:
Повторяется после полного выхода и запуска:
```

Приложите скриншот окна beta, если он помогает понять проблему. Имя, пароль
и личные данные профиля в отчёт не нужны. Если проверка прошла, тоже полезен
короткий отчёт: устройство, Android, обе версии и какие шаги выполнены.

## Изменения документации и канала

- Изменения beta направляются в main этого репозитория. Стабильная документация
  живёт в [app.slovoplet](https://github.com/iluhin/app.slovoplet).
- Описывайте, что проверено автоматически, что — на телефоне, а что ещё запланировано.
- Не правьте подписанный манифест вручную и не заменяйте уже опубликованные blobs.
- Ключи и пароли подписи не добавляются в репозиторий. Открытый ключ публикуется для проверки.
- Обновление компонентов готовится по [порядку выпуска](docs/RELEASING.md).

Публичный репозиторий содержит готовые сборки и справку. Основной код приложения
хранится отдельно; сборка APK не выполняется из этого публичного репозитория.
