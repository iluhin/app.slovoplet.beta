- [x] Виджеты и шорткаты из стабильного плана2.8.

## Проверка владельцем

- [ ] Установка APK 3.1 поверх исправленной beta, сохранность данных.
- [ ] Реальные виджеты, светлая/тёмная тема и 4×2.
- [ ] Шорткаты в выбранном лаунчере, возврат в начатую партию.
- [ ] Московская полночь при другом часовом поясе устройства.
- [ ] Жизненный цикл Android/WebView, контроль запуска и откат на устройстве.
- [ ] Расход батареи за сутки.

## Следующие задачи

- [ ] Серверный API виджетов без учёта присутствия — для фонового свежего рейтинга.
- [ ] Живой счётчик загрузки: пока размер показывается после завершения.
- [ ] Универсальная публикация следующего номера вместо фиксированного выпуска.
- [ ] Регулярная автоматизация на Android-эмуляторе/устройстве.
- [ ] Политика хранения и очистки старых снимков.

Нумерация beta независима. Монеты и дуэли остаются отдельными задачами.
