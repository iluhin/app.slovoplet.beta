# План beta-разработки

[Главная beta](README.md) · [История](CHANGELOG.md) · [Проверки](docs/VERIFICATION.md)

Это план beta-канала обновлений, а не замена общего плана развития игры.
Следующие пункты не обозначают уже выпущенные возможности; сроки пока не назначены.

## Реализовано

- [x] Отдельный beta-пакет и установка рядом со стабильной игрой.
- [x] Версии оболочки и компонентов видны раздельно.
- [x] Подписанный канал и доставка изменённых веб-файлов по SHA-256.
- [x] Отложенное применение без автоматического прерывания партии.
- [x] Подтверждение запуска и восстановление последней рабочей версии.
- [x] Пара 3.0 → 3.0.1 и контрольный APK для чистой установки.
- [x] Предварительные GitHub-релизы, не заменяющие стабильный Latest.
- [x] Автоматические проверки загрузчика и браузерного интерфейса.

- [x] Отдельный публичный репозиторий для beta-документации и выпусков.

## Сейчас — проверка на телефонах

- [ ] Чистая установка APK 3.0 на поддерживаемом Android.
- [ ] Получение 3.0.1 из сети и применение без системного установщика.
- [ ] Повторный запуск 3.0.1 без сети с сохранением партии и настроек.
- [ ] Возврат в приложение после сворачивания, закрытия и смены ориентации.
- [ ] Реальный 30-секундный контроль запуска и откат в Android/WebView.

Результат тестирования присылайте [по шаблону](CONTRIBUTING.md). Автоматические
проверки уже выполнены; пункты выше требуют устройства и пока не отмечены как пройденные.

## Следующие задачи

- [ ] Следующая APK-оболочка с новым origin OTA; проверка перехода со старого канала.

- [ ] Живой счётчик загруженных файлов/байтов: сейчас числа показываются по завершении.
- [ ] Универсальная публикация следующей beta-версии вместо workflow фиксированной пары 3.0/3.0.1.
- [ ] Регулярные инструментальные проверки на Android-эмуляторе или устройстве.
- [ ] Контролируемая очистка старых снимков компонентов и политика хранения.
- [ ] После проверки beta — решение о переносе механизма в стабильную оболочку.

Новые нативные возможности требуют отдельного APK. Доставка DEX и нативных
библиотек через канал компонентов в этот план не входит.
